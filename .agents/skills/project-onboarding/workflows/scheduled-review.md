# Scheduled review

Read the approved WorkObject, governor and phase/wave map. Bind one existing supported automation to the project governor when the owner has selected its cadence and time zone. Use the app automation action and verify the returned target and schedule. A dry run renders the review from local evidence. Use the current chat or a bounded status check for a particular active job.

Standing prompt:

> Read the scoped roadmap, current ISA criteria, phase and wave handoffs, pinned revisions and verified receipts for this WorkObject. Compare statuses with the previous review. Report material drift, blockers, finished children eligible for archive review and one next decision with its owner and source. Keep the review read-only. Treat missing receipts and unreachable sources as unknown. Notify the governor on material changes.

Use existing Temperance lifecycle. Cadence approval applies to review.
