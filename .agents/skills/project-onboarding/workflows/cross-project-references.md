# Cross-project references

Walk through one WorkObject at a time. Start from the project handoff, repo and design authority. Record source, revision, owner, visibility, flow and what the source proves. Inventory React Native architecture, voice-agent orchestration and fallback, recurring UI flows, components, tokens, nuanced style docs, Claude artifacts and screen references. Treat collections of screens as references organized by journey and state.

Compare a complete representative flow first, including entry, normal progress, interruption and recovery. Capture three items with evidence: reusable functionality or interaction principles, the design-system decisions specific to that app, and ideas still being tried. Preserve differences in consent, failure behavior, typography, motion and density. Link originals rather than copying private artifacts or design systems.

Use Cambium for project and work references. Resolve the existing Taste Cortex interface on demand and connect reviewed design references where its authority allows. Hold unknown or unverified links as such. A deep comparison belongs in the explicitly requested side chat.
