# Cambium visual-flow references

These two images are selected concept assets from the Cambium visual-flow
organ-console export, used as atmosphere in the Library interface. They are
static artwork. Library counts, saved-item states, categories, and group
actions come from Library data and Chrome APIs, never from the artwork.

in the Cambium project backup. No held, generated-pending-review,
unresolved, or duplicate source assets are included.

The teal, lime, mint, cream, and peach palette; condensed headings; mono
telemetry; orbit/ring mark; and restrained interaction states derive from
`CVF-SRC-0063` (Cambium design-system board) in the visual-flow source
library. The interface implements these as local CSS and SVG; it does not
embed the design-system screenshot.

These reference assets are local to the extension package. They are not
published to websites or sent to an AI provider by the Library.
