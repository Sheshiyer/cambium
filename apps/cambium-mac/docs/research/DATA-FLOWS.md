# Directional integration map

2 November 2026. Research map of existing source contracts and proposed native
joins. It is not a new registry or runtime graph. Status **source** means an
inspected declaration/implementation; **dated** means bounded historical proof;
**proposed** means the native path remains to build. No row asserts live end-to-end
health merely because the related source exists.

## Infrastructure, history and peer products

Cloudflare Worker serves guarded application contracts. D1 owns operational intent;
KV supplies stored projections; R2 holds immutable evidence/artifacts; Vectorize
is a retrieval adapter. The native client uses owner APIs rather than direct cloud
credentials. Queues, triggers and cron are owner mechanisms, not implied by a
notification setting.

GitHub holds source/roadmap/release coordination. The old surface inventory's
“GitHub/Cloudflare CI” row predates the recorded Actions retirement: a native
release plan must discover current release jobs rather than revive that automation.

Session Atlas is a scoped history projection, not permission to import Codex,
Claude or other native session stores. Antahkarana is an independent optional
workflow adapter. Snow Gloves is an independent optional product. Neither becomes
a required Cambium app runtime simply because an old diagram draws an edge.

A concurrent repository-owned `sapling-lifecycle` source pack exposes review,
new, run, graph, draft, grow, learn and status intents. Its helper prepares reports
and dispatch briefs; the calling agent owns a selected authorized action. It
creates no scheduler, admission or native launcher. The new app can expose those
lifecycle intentions through a reviewed adapter later, without interpreting
`prepared` as executed. Its source is a separate concurrent lane and was not
changed by this discovery.

Connected product branches retain their own repositories, release, provider and
customer-data boundaries. For example Fitcheck uses separately owned HDILINT,
Shopify, Vercel, AWS App Runner, Dodo and optional Composio. The app should expose
those typed dependencies and evidence links; building native Cambium does not
rebuild or administer every connected product.
