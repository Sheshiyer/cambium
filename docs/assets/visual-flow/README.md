# Cambium visual-flow assets

This directory contains visual-flow references used across Cambium surfaces.

- The numbered files at this level are the pre-existing Telegram Mini App and R3F reference corpus. They remain unchanged and retain their original filenames.
- [Source library](source-library/README.md) maps and renames those 46 numbered visual assets into Telegram, organ, component, turntable, product-page, brand, contact-sheet, and unresolved-model families without replacing the originals.
- [Organ Console](organ-console/README.md) contains the governed, owner-segregated export of Organ Console organs, semantic features, page views, and review boards.
- [System atlas portraits](system-atlas/README.md) bundles eleven hash-bound derivatives for the Mini App and [visual source guide](../../explainers/system-atlas-2026-10-07/index.html). The original files and unresolved models retain their existing status.

Both organized packages are reference-only. Their machine maps preserve identifiers, ownership or source role, dimensions, hashes, and duplicate/lineage evidence without copying raw prompts or machine-local generation metadata.
