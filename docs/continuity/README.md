# Continuity records

This directory preserves active cross-system planning that would otherwise be lost
between repository evidence, runtime state, and GitHub coordination.

Continuity records may map source IDs, dependencies, evidence classes, approval
gates, probes, and owning issues. They are not runbooks and never authorize a
provider, runtime, registry, session, credential, or deployment mutation.

Before changing an item's status:

1. Re-probe the named authoritative source.
2. Record the evidence class and observation time.
3. Reconcile the owning GitHub issue.
4. Update the linked roadmap phase when sequence or scope changes.
