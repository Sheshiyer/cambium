approval for the exact reviewed commit and release intent. The release must use
the existing isolated-clean-clone procedure in `workers/quests/DEPLOY.md`, first

Stop if any condition fails:

- the checkout is dirty or diverges from the reviewed commit;
- deterministic preflight fails;
- the drift audit reports stale canonical visual proof;
- the Worker does not have one known-good 100-percent rollback version;
- signed Mini App gate readback is not healthy;
- the generated projection marks a deferred quest as terminal; or
- the release would require a product, provider, Shopify, payment, CRM, R2, or
  Telegram mutation beyond publishing the Worker artifact.
