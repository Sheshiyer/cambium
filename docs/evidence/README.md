# Evidence

Evidence is immutable, dated proof of an observed state. It is not an operator procedure and does not supersede current contracts, runbooks, or the project ISA. See [`../LIFECYCLE.md`](../LIFECYCLE.md).

Use evidence to verify a claim, understand a historical decision, or trace a bounded change. Do not edit a dated receipt to represent current state; produce a new dated evidence record instead.

For active procedures, use [`../runbooks/`](../runbooks/). For historical implementation plans and their proof assets, use [`../plans/`](../plans/).
