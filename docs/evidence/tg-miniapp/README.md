# Telegram Mini App evidence

This tree contains immutable, dated evidence. It is not a source of current
readiness and must not be used as an operator checklist.

Current proof capture writes redacted temporal artifacts under ignored
`.artifacts/tg-miniapp-live-proof/`. CI uploads its generated readiness report.
When a completed founder-device proof is worth preserving, copy the validated,
redacted artifact and screenshot into a new dated evidence directory with an
explanation of exactly what it proved.
