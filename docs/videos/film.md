# Cambium Fractal Ecosystem Hero

This FilmSpec is a bounded storyboard for a future approved product video.
It intentionally uses cards and a mark until guide stills exist. No motion
capture or voiceover run is claimed by this file.

No project-local `product-marketing-context.md` was found during preparation,
so the FilmSpec leaves `wordsToAvoid` empty rather than inventing positioning
rules. Populate that source before treating this storyboard as final.

The story follows the same fractal sequence as the guide: project root,
planning, skill ownership, workflow gates, capture boundary, and approval
stop. Composition begins only after the guide manifest has real evidence and
the owner approves the bounded video operation.
