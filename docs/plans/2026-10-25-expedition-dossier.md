# Expedition Dossier

The founder needs to understand where a proposal fits, what it changes, and what can happen next before reading its machine record. The current folio puts raw identifiers and canonical JSON ahead of those decisions.

## Direction

Use an expedition journal: a strong briefing, narrow context rail, discrete objective steps, evidence, and an explicit decision footer. Retain the atlas paper, petrol and copper identity; use restrained acid accents for focus and verified state. A constellation-first atlas would obscure the decision; a loadout-first ledger would overemphasize tools. Those remain supporting context.

Macro explains purpose and scope. Meso explains authored location and explicit branch/organ relationships. Micro explains the exact objective, state, evidence requirement and next action. A district is navigation context, never proof of an executing organ. Missing phase, branch or organ data remains unassigned. Source-defined connections and local exploration remain distinguishable from operational evidence.

## Motivation and trust

Octalysis informs meaning, mastery, feedback, ownership, relationships and discovery. No fabricated XP, rarity, percentage completion, urgency or execution state. Expiry is the actual approval window. The real receipt path advances only from authoritative events. Full canonical review remains available through a native disclosure; consequential changes and safeguards remain visible before decision controls.

## System

Use existing system fonts with editorial headings, readable body copy and compact monospaced metadata. Consolidate colors, spacing and strokes into scoped CSS tokens. Keep labels readable, state redundant with text, focus visible, controls at least 45 CSS pixels and layout contained at 320 pixels. Use native disclosures and reduced-motion-aware transitions. No new font, animation library, external asset or runtime service.
