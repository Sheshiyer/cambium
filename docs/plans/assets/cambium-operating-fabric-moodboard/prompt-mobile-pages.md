# Cambium Operating Fabric — Mobile Pages Moodboard Prompt

Create one polished landscape product-design moodboard containing six portrait mobile page studies for the Cambium Telegram Mini App.

Asset:
- 1536×1024 landscape board.
- Six narrow 9:16 mobile frames or cropped page studies arranged as an editorial system.
- Product UI reference, not a marketing poster and not photoreal phone hardware.

Reference invariants:
- Cambium R3F moodboard: dark teal topographic depth, organic glyph meshes, signal rails, packet dots.
- Constellation UI reference: map overview, selected node view, workforce network, compact telemetry and permission paths.
- Telegram Mission Control reference: native mobile hierarchy, exact chartreuse/peach state language, thin cards, safe-area spacing, readable operator density.

The six page studies:

1. “CANOPY”
   - two zones: “SAPLINGS” and “PROGRAMS”
   - selected work node with halo
   - compact counts for active, blocked, stale

2. “MISSION”
   - selected work context
   - “NEXT MISSION”
   - four-stage timeline
   - blockers and proof

3. “FLOW”
   - task lanes from queued to receipt
   - dependency rails
   - one agent assignment rail
   - one dotted skill requirement rail

4. “WORKFORCE”
   - human founder hub plus distinct agent nodes
   - current task, permission, availability
   - no productivity leaderboard

5. “FORGE”
   - skill-cluster nodes
   - available, active, degraded states
   - pinned loadout sheet teaser
   - candidate → validated → production

6. “GATE + INSPECT”
   - contextual bottom sheet
   - “REVIEW CHANGE”
   - consequence, reversibility, freshness, D1 version
   - primary “APPROVE”, secondary “INSPECT”

Shared navigation:
- Bottom or top root navigation exactly: “CANOPY”, “MISSION”, “FLOW”, “WORKFORCE”, “FORGE”.
- Gate and Inspect are contextual sheets, not primary tabs.

Visual encoding:
- Node kind uses silhouette and glyph.
- State uses color, icon, and rail.
- Freshness uses opacity and a tiny timestamp.
- Authority uses a tiny chip such as “D1 · v42 · read”.

Palette:
- #00272B deep base
- #012F34 surface
- #E0FF4F active
- #D6FFF6 highlight
- #231651 deep shadow
- #FFC7A1 warning
- off-cream text

Typography:
- Condensed sans for page titles.
- Humanist sans for primary labels.
- Tiny mono for telemetry.

Do not:
- No generic SaaS cards, purple/blue AI gradients, glossy buttons, decorative orbs, robots, buildings, fake URLs, tokens, logos, watermarks, or dense paragraphs.
- Do not make agents or skills look like project types.
- Do not imply that a read projection mutates state.
- If exact text is difficult, prioritize page hierarchy, glyph differentiation, and state grammar.
