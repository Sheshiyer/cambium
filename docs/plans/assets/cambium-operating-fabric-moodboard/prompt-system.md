# Cambium Operating Fabric — System Moodboard Prompt

Create one polished landscape visual-direction board for the Cambium Operating Fabric.

Asset:
- 1536×1024 landscape product/system moodboard.
- High-end UI art direction, not a literal engineering diagram.
- Visually buildable in HTML/SVG/R3F: shallow extruded glyphs, rails, rings, packet dots, labels, panels.

Reference invariants:
- From the Cambium R3F visual moodboard: deep teal cartographic field, organic-precise extruded glyphs, topographic contours, hyphae rails, particle packets, calm bioluminescent material.
- From the constellation UI reference: clear overview-to-node hierarchy, founder/workforce network, selected halos, permission rails, compact instrument panels.
- From the Telegram Mission Control reference: portrait-mobile density, chartreuse active state, peach blocked state, thin borders, mono telemetry, proof and gate clarity.

Core concept:
- A company-wide “Canopy” at the top with two honest work families.
- Left family: “SAPLINGS” — new ventures moving through a proof-bound branch ladder.
- Right family: “PROGRAMS” — company, client, capability, and operations initiatives moving through outcome lifecycles.
- Both converge into one central flower-like “MISSION FABRIC”.
- From the Mission Fabric, show a precise lineage: “MISSION” → “TASK” → “RUN” → “RECEIPT”.
- Overlay a distinct “WORKFORCE” region with human/agent flower nodes connected to tasks by solid assignment rails.
- Overlay a distinct “FORGE” region with skill-cluster hex nodes connected to tasks by dotted double rails.
- A protected bottom spine labeled “D1 AUTHORITY” is the only writer.
- A side feedback loop labeled “CORTEX” returns learning to a new proposal, never directly to authority.

Visual encoding:
- Sapling = starburst seed glyph.
- Program = ring or tree-ring glyph.
- Mission = capsule.
- Task = precise square tile.
- Agent = small flower or compass glyph.
- Skill cluster = hexagonal cluster.
- Receipt = folded rectangular packet.
- Active = chartreuse solid rail and core.
- Blocked = peach warning icon and broken rail.
- Stale = lower opacity plus tiny timestamp.
- Read projection = small lock/read chip.

Do not:
