## Capture and qualification

`npm run proof:field-atlas` captures real PAGE/browser observations into a new
ignored directory. `npm run proof:field-atlas -- --write-canonical` additionally
publishes the current source artifacts from an unchanged clean commit. The
publisher stages a complete validated set, preserves an existing canonical set
before replacement, and restores it if final publication fails. Historical
2D assets are never republished or restamped.

Each frame binds the rendered PAGE, committed source files, instruction digest,
exact CSS viewport/PNG dimensions, image bytes and actual browser assertions.
Header separation, visible text bounds, accessible control names, minimum44px
controls, modal containment, source/authority labels and retired-surface absence
are observed in the browser. Console errors, uncaught exceptions, failed requests
and bad responses fail the capture; software WebGL warnings are counted. Native
pointer input is used, with screenshots and separate keyboard/touch QA. This is
local software WebGL evidence, not physical-device or trusted-touch release
acceptance.

Operational journeys use the existing founder bridge against a **synthetic local
server**. Session, tenant, proposal, canonical-review and exact-method contracts
are exercised. Input hashes and method counters are retained. Proposal POSTs are
read-only; decision/renewal and unexpected requests are denied and fail evidence.
There is no production identity, credential, D1 owner, graph mutation or execution.

The current source matrix has 44frames: responsive entry/world/chart/Departments,
source directory/folios, held and verified-empty Gate states, exact complete
proposal reviews, separate approval preflights, inspection back/close, and local
visits in both unavailable and available source-read contexts.

`npm run drift:audit` validates fresh source artifacts plus every immutable legacy
image/step/identity. `npm run proof:field-atlas:check` is the **strict qualification
gate** invoked by release verification before later checks. The compatibility
`proof:tg-mobile-contract` command invokes the same strict gate. Source freshness
alone never makes retained operational qualification pass.
