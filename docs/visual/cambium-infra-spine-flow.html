Portfolio plane

The Workbench reads the catalog and roots; checked-in data stays the canonical source. Writes only travel through /v1/admin/portfolio/actions, never directly.

Durability plane

The host-configured filesystem holds promoted and shallow folders. R2 holds immutable evidence only — never live state, code history, or Goal Graph writes.

Signal plane

Hermes owns Telegram transport and cron delivery, compiling bounded intent. Plexus resolves identity and RBAC before any UI affordance is shown.

Surface plane

Mini App scenes project the same facts across Mission, Flow, Workforce, and Forge. MCPs and plugins stay held/deferred pending Git identity.

Status: doctrine reference. It documents authority boundaries and grants no deployment, provider, storage, or operational-write authority.
