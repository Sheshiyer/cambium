<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository files → compiler | Untrusted paths, bytes, selectors, declared digests, and lifecycle assertions enter the pure projection lane. |
| Canonical anchors → overlays | Only references and digests may cross; doctrine content and authority cannot be copied. |
| Intent/D1 projections → authority sources | Derived projections must never fold back as fresh ISA, GSD, doctrine, or D1 input. |
| State semantics → completion display | Blocked, stale, missing, gated, stopped, and complete states must remain distinguishable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | Source authority and overlay anchors | mitigate | Closed authorities, exact root-anchor targets, reference-only overlay validation. |
| T-04-02 | Tampering | Source paths, digests, IDs, ordering | mitigate | realpath containment, canonical UTF-8/LF hashing, stable semantic IDs, sorted output, digest recomputation. |
| T-04-03 | Repudiation | Evidence/learning close and renew edges | mitigate | Named source selectors, typed transitions, immutable read-only output, graph digest. |
| T-04-04 | Information disclosure | Source bodies and local paths | mitigate | Repository-relative paths only; outputs contain references/digests and never source text. |
| T-04-05 | Denial of service | Cycles, duplicate IDs, invalid endpoints | mitigate | Bounded finite input validation, duplicate rejection, endpoint validation, deterministic sort. |
| T-04-06 | Elevation of privilege | Projection foldback and false completion | mitigate | Reject both projection schemas as authority input and reject blocked plus satisfied states. |
| T-04-SC | Tampering | npm supply chain | accept | No package install, manifest edit, or lockfile change; Node built-ins only. |
