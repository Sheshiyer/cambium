<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI argv to parser | Revision, root, and unknown flags are untrusted and must be closed before Git access. |
| Compiler throw to stderr | Diagnostics must not leak checkout paths, Bearer tokens, or source bodies. |
| Package script to repository | Inspection must not acquire write authority or hide a moving revision. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01 | Spoofing | high | CLI revision | mitigate | Require caller revision, resolve full SHA, echo only immutable identity; reject `${rev}^{tree}` and absolute revision text. |
| T-07-02 | Tampering | high | dirty tree substitution | mitigate | CLI never reads worktree bodies; tests dirty the fixture and assert SHA-bound receipt unchanged. Compiler isolation remains 07-01. |
| T-07-03 | Tampering / DoS | high | phrase false-fail | mitigate | CLI does not add a whole-corpus phrase scan; it calls compileDeterministicSafety only. HEAD-pass remains a 07-01 contract. |
| T-07-04 | Tampering / Repudiation | high | digest mismatch | mitigate | CLI publishes no replacement projection; stale digest throws from the compiler and becomes a non-zero exit with relative path. |
| T-07-05 | Information Disclosure | high | stderr/stdout | mitigate | safeDiagnostic redaction; tests forbid /Users/ and /Volumes/; no partial stdout document; no source bodies. |
| T-07-06 | Elevation of Privilege | high | write-on-hit | mitigate | Closed parser rejects --write/--output/--fix; snapshot tests prove zero file/index mutation on success and failure. |
| T-07-07 | Spoofing | high | GSD closeout spoofing | mitigate | This plan does not edit ISA, HANDOFF, STATE, ROADMAP, or REQUIREMENTS. Closeout remains 07-03. |
