<interfaces>
- `deriveRalphIteration(flow, externalResult?)` is pure. It cannot read files, run commands, write summaries/state/handoff, dispatch work, call providers, or retain module-global mutable state.
- `runRalphIteration(options)` is the bounded outer adapter. It rereads the declared projection/sources for each call; invokes exactly one injected external executor only after all gates; runs the selected task's declared verification; appends evidence to an existing plan summary, updates the existing GSD state through the declared adapter, appends the reviewed handoff, and exits. It creates no other state file or queue.
- Before external execution it returns exactly one declarative envelope: selected task ID, exact command, route intent, receipt gate, approval gate, declared verification, declared persistence surfaces, immutable pre-effect source snapshot digests, and external stop condition; or `blocked` with no command.
- Paid execution requires the fixed host-owned Manifest verifier to return an owner-approved receipt result with fixed issuer/audience, issued/expires times, nonce, exact selected task/command/route/projection digest, and replay-consistent approval digest. Raw receipts, custom verifier endpoints, and caller-selected trust roots are non-authoritative. Missing, unverified, wrong-issuer/audience, stale/future, mismatched, denied, or replay-conflicting approval blocks execution.
- After an externally supplied result it returns `stop` with one of `verification_failed`, `persist_required`, `approval_required`, `terminal`, or `iteration_complete`. It never marks a task/project complete itself.
- Replay of equal inputs is byte-stable; the same iteration key with different projection/result digest conflicts. A completed or terminal envelope cannot be revived.
- The runbook names external owners: native Codex babysits, an authenticated host receipt proves resolution, `te-dispatch-paid` executes only after authenticated matching approval, declared test commands verify, existing GSD summary/state and reviewed handoff persist, and the next fresh invocation rereads all durable truth.
</interfaces>
