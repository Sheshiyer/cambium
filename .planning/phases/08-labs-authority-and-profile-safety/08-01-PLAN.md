# Plan 08-01: Freeze Labs Authority and Profile Safety

## Objective

Make `thoughtseed-labs` the only repository-recognized production profile,
keep `9d9d` read-only, publish the complete stable Cloudflare resource map,
and leave all external mutation behind explicit later gates.

## Tasks

### Task 1 — Test and implement the profile resolver

- Prove JSONC parsing preserves URLs and comments.
- Validate Worker, account, route, Access team, D1, KV, R2, and Vectorize.
- Permit Labs read/write/deploy and legacy read-only.
- Reject unknown profiles, unknown operations, and legacy write/deploy.

### Task 2 — Publish the stable map and canonical runbook

- Store stable identities and per-primitive strategy without secrets or
  mutable counts.
- Require the resolver receipt before operator commands.
- Use explicit Labs config/profile selectors for production examples.
- Mark the legacy `9d9d` documentation path read-only and historical.

### Task 3 — Align milestone authority and handoff

- Activate v0.5 and Phase 8 across STATE, ROADMAP, PROJECT, ISA, and the
  Temperance goal.
- Record the clean branch order separately from the Telegram and admission
  branches.
- Preserve Cloudflare mutation, merge, and retirement as external gates.
