non-authoritative intake sidecar. Preserve the existing inventory and evidence
resolver semantics while making unmapped and incomplete coverage explicit.

**Files:** `apps/portfolio-cartographer/scripts/repository-intake.mjs`,
`apps/portfolio-cartographer/scripts/repository-intake.test.mjs`.

**Action:** Build a pure validator, reconciler, and deterministic renderer for
`thoughtseed.repository-intake.v1`. Reject unsafe paths and malformed identities.

separate fields. Do not import or modify `REPOSITORY_INVENTORY`.

**Verify:** Fixture tests prove that pending intake cannot alter legacy
repository-evidence resolution, path escapes fail, ordering is stable, and partial

### Task 2: Reconcile the current bounded observations

**Files:** `docs/project-management/repository-intake.v1.json`, a private-free
input snapshot under the quick-task receipt directory.

**Action:** Use read-only, bounded owner and local repository metadata to create
the current intake snapshot. Preserve exact existing root-map proposal relations;
classify only exact evidence as mapped. Keep recent unmatched repositories as
`awaiting-ingestion`, nested Decodik as mapped/nested, and off-root observations
as external without creating a portfolio placement.

**Verify:** The snapshot contains no absolute paths, raw remotes, credentials,
prompts, account emails, or invented WorkObject IDs. Cambium Website and Decodik
retain their corrected meaning.

### Task 3: Wire safe check/write behavior and document it

**Files:** `apps/portfolio-cartographer/scripts/repository-intake.mjs`,
`apps/portfolio-cartographer/package.json`, `apps/portfolio-cartographer/README.md`,
`.planning/quick/260907-7q6-add-repository-intake-observation-sidecar/260907-7q6-SUMMARY.md`,
`.planning/STATE.md`.

**Action:** Make default operation a no-write check. Require an explicit write
flag to update only the sidecar. Document scope, evidence boundaries, and how to
refresh from an authenticated read-only snapshot. Record exact verification and
the unchanged mapping/routing boundaries.

**Verify:** Import/check performs no network or write side effect; explicit write
touches only the declared sidecar; focused tests and the existing Cartographer
test suite pass.
